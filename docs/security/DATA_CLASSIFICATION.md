# Clasificación de Datos

1. **Datos Públicos:** Catálogo comercial de planes del SaaS, nombres de las funcionalidades.
2. **Datos Internos de la Organización:** Catálogo de servicios, precios, listas de personal.
3. **Datos Privados (PII):** Nombres, cédulas, correos y teléfonos de los Representantes y Beneficiarios. Manejo estricto.
4. **Datos Sensibles:** Expedientes de los menores, evaluaciones psicológicas, notas de terapias, discapacidades. Requieren un nivel de autorización estricto dentro de la organización.
5. **Datos Financieros/Tributarios:** Certificados de firma electrónica (`.p12`), claves SRI. Se encriptarán at-rest y NUNCA estarán disponibles en el frontend.
