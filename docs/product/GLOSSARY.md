# Glosario

- **SaaS:** Software as a Service.
- **Tenant (Inquilino):** Representado por `Organization`. Una instancia aislada de cliente (una guardería o centro).
- **RLS:** Row-Level Security de PostgreSQL.
- **Entitlement / Feature:** Un derecho o límite que una organización tiene sobre un módulo según su suscripción.
- **SRI:** Servicio de Rentas Internas del Ecuador.
- **RIDE:** Representación Impresa de Documento Electrónico.
- **XML:** Archivo estructurado y firmado con validez tributaria.
- **Recibo Interno:** Documento de cobro no válido tributariamente (para uso administrativo de organizaciones que no habiliten SRI).
