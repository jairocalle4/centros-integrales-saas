# Roadmap del Producto (NexoKids)

**Fase 1 — MVP Administrativo:**
- Autenticación, tenants, roles, beneficiarios.
- Servicios, asistencia, cargos y pagos simples.
- Dashboards básicos.

**Fase 2 — Operación Profesional:**
- Evaluaciones, planes de intervención, expedientes.

**Fase 3 — Facturación Electrónica SRI:**
- Emisión de facturas reales para clientes ecuatorianos.

**Fase 4 — Integraciones Futuras:**
- WhatsApp, portales de apoderados, PWA.
