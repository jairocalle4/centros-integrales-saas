# Reglas Web (React/Vite)
Aplica a: `apps/web/**`

1. **Stack:** React, TypeScript, Vite, TanStack Query, Tailwind CSS.
2. **Estado:** No usar Zustand ni librerías de estado global hasta que React+TanStack Query no puedan resolverlo.
3. **Linting/Formatting:** Usar ESLint y Prettier exclusivamente (evitar herramientas redundantes).
4. **Testing:** Vitest y React Testing Library. 
5. **No quemar IDs:** Nombres de planes comerciales o IDs de tenant no deben estar hardcodeados en los componentes.
