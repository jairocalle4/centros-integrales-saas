# NexoKids Web App

Este es el frontend administrativo de NexoKids, construido sobre React y Vite.

## Stack
* React 19
* Vite 8
* Tailwind CSS 4
* React Router
* Supabase JS Client

## Comandos
* `pnpm dev`: Iniciar servidor de desarrollo local.
* `pnpm build`: Generar bundle optimizado para producción.
* `pnpm test`: Ejecutar pruebas unitarias con Vitest y Testing Library.
* `pnpm lint`: Validar código con oxlint.
* `pnpm typecheck`: Validar TypeScript (tsc).
